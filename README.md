# NFT Access Bot

Telegram-бот проверки NFT-доступа к закрытому каналу: по адресу кошелька
проверяет владение ключом и выдаёт доступ (инвайт-ссылка в закрытый канал).

**Стек:** Python 3.11, aiogram 3, SQLite. Опционально `pytoniq` / `tonutils`
для on-chain проверки владения NFT.

## Что делает

- `/start` — приветствие, кнопка «Проверить мой доступ»
- проверка адреса по whitelist NFT-ключей: доступ открыт / срок истёк / не найден
- автовыдача одноразовой инвайт-ссылки в закрытый канал
- `/revoke` — отзыв доступа (админ)
- журнал операций в лог

## Запуск

```bash
pip install aiogram
export BOT_TOKEN=123456:AA...
export ADMIN_CHANNEL_ID=-1001234567890
export NFT_CONTRACT=EQ...
export COLLECTION_NAME="Access Keys"
export KEY_TTL_DAYS=30
python bot.py
```

## Что заменить в бою

1. `check_ownership()` — сейчас это whitelist в SQLite. В бою здесь запрос к
   NFT-контракту (item index по адресу) либо сверка с таблицей продаж вашего
   Telegram-магазина.
2. `grant_access()` — сейчас возвращается тестовая ссылка. В бою:
   `bot.invite_link(chat_id=ADMIN_CHANNEL_ID, expire_date=...)`.
3. Таблица `keys` — синхронизировать с продажами автоматически: при покупке
   бот сам пишет адрес и тариф, при возврате NFT снимает доступ.

## Демо-страница

`index.html` — статичная демонстрация проверки кошелька (симуляция), удобно
показывать клиенту как «как это выглядит». Тестовые адреса:

| Адрес | Результат |
|---|---|
| `EQDemo_Owner_0000000000000000000000` | доступ открыт |
| `EQDemo_User_1111111111111111111111` | срок ключа истёк |
| `EQDemo_Stranger_9999999999999999999` | NFT не найден |
