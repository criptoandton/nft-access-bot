NFT Access Bot

Бот проверяет по адресу кошелька наличие NFT-ключа и выдаёт доступ к закрытому каналу. Реальный бот делает то же самое, но запрос идёт в блокчейн и в API канала.

Проверить кошелёк

Введите адрес кошелька и нажмите «Проверить доступ».

Как это работает

  1. /start — пользователь подключает кошелёк (Tonkeeper или WebApp).
  2. Проверка — адрес сверяется с whitelist ключей коллекции.
  3. Владение — item index по адресу в NFT-контракте.
  4. Выдача — одноразовая инвайт-ссылка в закрытый канал.
  5. Отзыв — при возврате NFT доступ снимается автоматически.
